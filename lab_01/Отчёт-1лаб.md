## Теоретический материал
Тип данных float (Числа с плавающей точкой) используется для
представления вещественных (дробных) чисел. Встроенная функция float()
также позволяет преобразовывать другие типы данных (например, строки или
целые числа) в числа с плавающей точкой.
Функция input() приостанавливает выполнение программы и ждет, пока
пользователь введет текст с клавиатуры и нажмет Enter.
Функция round() используется для округления чисел до определенного
количества знаков после запятой.
Функция print() выводит текстовую информацию на экран (в консоль). Она
может принимать любое количество аргументов, разделенных запятыми.
Программирование на Python: Лабораторный практикум Язык Python является
интерпретируемым. При первом запуске код транслируется в промежуточный
байт-код и выполняется виртуальной машиной . Переменные представляют
собой ссылки (имена), связанные с объектами в динамической памяти.
Отступы (ровно 4 пробела) обязательны и служат для группировки блоков
кода. Метод format() позволяет выполнять форматирование в соответствии
со спецификацией PEP 3101. Например, выражение '{0:.3f}'.format(pi)
форматирует вещественное число с точностью до трех знаков после запятой.
Вместо метода format() можно использовать f-строки.
Напишите скрипт, вычисляющий физическую величину по формуле. Все
переменные должны быть динамически привязаны к значениям. Вывод
результата осуществить строго с помощью f-строк с округлением
вещественной части до 4 знаков после запятой.
