## Теоретический материал
Условный оператор if-elif-else: Используется для проверки логических
условий и ветвления алгоритма. Конструкция elif позволяет связывать
несколько последовательных проверок без добавления лишней вложенности
отступов. Блок else выполняется, если ни одно из условий не подтвердилось.
Обязательным синтаксическим правилом является использование двоеточия
(:) и строгое соблюдение отступов (4 пробела).
Цикл while: Выполняет блок выражений до тех пор, пока проверяемое
условие истинно (True). Для экстренного выхода из цикла применяется
оператор break, а для перехода к следующей итерации — continue. При
естественном завершении цикла выполняются команды из необязательного
блока else.
Цикл for..in и функция range(): Осуществляет перебор элементов
последовательности (списков, строк или диапазонов). Встроенная функция
range(start, stop, step) генерирует арифметическую прогрессию чисел,
не включая верхнюю границу stop.
Пользовательские функции (def): Представляют собой многократно
используемые блоки кода с собственным именем. Функция объявляется с
помощью ключевого слова def, принимает параметры и возвращает
результаты вычислений оператором return. Строки документации
docstrings (в тройных кавычках) размещаются сразу после заголовка
функции для описания ее назначения.
## Индивидуальное задание:
Написать функцию neutralize_ph(start_ph), моделирующую в цикле
добавление щелочи (+0.5 pH) при pH < 6.5 или кислоты ( 0.5 pH) при pH > 7.5.
Цикл останавливается при попадании pH в диапазон [6.5; 7.5]. Функция
возвращает число доз.
## Код программы
``` python
def neutralize_ph(start_ph):
cur_ph = start_ph
d = 0
while cur_ph < 6.5 or cur_ph > 7.5:
if cur_ph < 6.5:
cur_ph +=0.5
d += 1
elif cur_ph > 7.5:
cur_ph -= 0.5
d -= 1
return d
ifs = input("Введите начальные значения: ")
ph_val = list(map(float, ifs.split()))
for ph in ph_val:
r = neutralize_ph(ph)
print("Для значения", ph , "требуется", r, "доз.")
```
Введите начальные значения: 1 5 15 2
Для значения 1.0 требуется 11 доз.
Для значения 5.0 требуется 3 доз.
Для значения 15.0 требуется -15 доз.
Для значения 2.0 требуется 9 доз.
