## Теоретический материал
Модуль в Python представляет собой отдельный файл с расширением .py,
содержащий определения функций, переменных и классов. Модульная
архитектура обеспечивает повторное использование кода и декомпозицию
сложных программных комплексов.
Импорт модулей: lля подключения встроенных или внешних модулей
используется оператор import module. Для импорта конкретных функций
используется форма from module import function. Точка входа
__name__: при импорте модуля весь его код исполняется один раз. Чтобы
отделить код тестирования от используемого функционала, применяется точка
входа с проверкой специальной переменной if __name__ == '__main__’:
Системный модуль sys: Модуль sys предоставляет доступ к параметрам
среды исполнения. В частности, список sys.argv содержит аргументы
командной строки, переданные скрипту при запуске.
•Списки (list): Упорядоченные динамические массивы элементов
произвольных типов ([]). Являются изменяемыми (mutable), что позволяет
добавлять (append()), сортировать (sort()) и удалять (pop(), remove(),
del) элементы.
• Кортежи (tuple): Упорядоченные неизменяемые (immutable)
последовательности элементов (()). Кортежи применяются для защиты данных
от случайной модификации и возврата нескольких значений из функций.
• Словари (dict): Ассоциативные массивы, хранящие пары «ключ: значение»
({}). Ключи должны быть уникальными и неизменяемыми объектами (строки,
числа, кортежи).
• Множества (set): Неупорядоченные коллекции уникальных элементов.
Множества поддерживают математические операции: объединение (|),
пересечение (&), разность (-).
## Задачи модуля (variant_mod.py):
1) search_component(inventory_dict, item_name) — ищет компонент в словаре
ячеек складирования;
2) get_low_stock(inventory_dict, min_qty) — возвращает список кортежей (item,
qty) для компонентов с остатком < min_qty;
3) get_storage_zones(inventory_dict) — извлекает множество (set) уникальных
буквенных зон хранения.
Требования к программе main.py:
• Считать минимальный остаток min_qty из sys.argv[1] (дефолт 50).
• Задать инвентарный словарь склада, найти дефицитные детали и вывести
список уникальных зон.
## Код программы
```python
#variant_mod.py
def search_component(inventory_dict, item_name):
return inventory_dict.get(item_name)
def get_low_stock(inventory_dict, min_qty):
low_stock_list = []
for item in inventory_dict:
info = inventory_dict[item]
qty = info[0]
if qty < min_qty:
low_stock_list.append((item,qty))
return low_stock_list
def get_storage_zones(inventory_dict):
zones = set()
for item in inventory_dict:
info = inventory_dict[item]
zone = info[1]
zones.add(zone)
return zones
#main.py
import sys
from variant_mod import(get_storage_zones,get_low_stock)
def main():
if len(sys.argv) > 1:
min_qty = int(sys.argv[1])
else:
min_qty = 50
inventory = {'Resistor 10k': (120, 'Zone-A'),
'Capacitor 100uF': (30, 'Zone-B'),
'Microcontroller': (15, 'Zone-A'),
'Relay 12V': (80, 'Zone-C')
}
deficite_items = get_low_stock(inventory, min_qty)
storage_zones = get_storage_zones(inventory)
print("=== УЧЕТ АВТОМАТИЗИРОВАННОГО СКЛАДА ===")
print("Дефицитные детали (< " + str(min_qty) +" шт):",
deficite_items)
print("Буквенные зоны хранения (set):", storage_zones)
if __name__ == "__main__":
main()
```
